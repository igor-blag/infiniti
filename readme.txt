A bold WordPress block theme for children's digital education centers with a diagonal-split hero, deep blue and red accent palette, and fullscreen search overlay.

== Description ==

ИнфинИТи is a modern full-site editing block theme designed for children's digital education centers — centers that teach programming, robotics, 3D modeling, and digital creativity to school students aged 7–17.

It features a striking diagonal-split hero section, a deep blue and red accent color palette, a sticky header with backdrop blur, a fullscreen search overlay, and a confident forward-looking design.

**Features:**

* Full Site Editing (FSE) support
* Diagonal-split hero pattern
* Sticky header with blur backdrop
* Fullscreen mobile navigation overlay
* Fullscreen search overlay
* Custom block patterns for programs, advantages, CTA sections
* Responsive layout
* Custom color palette and typography via theme.json
* Demo content installer via admin notice

**Demo:** https://infiniti.no-it.ru

== Privacy ==

This theme does not collect, store, or transmit any user data. No tracking, analytics, or third-party services are used. Google Fonts are loaded from external servers; see the Resources section below for details.

== Installation ==

1. Upload the `infiniti` folder to `/wp-content/themes/`.
2. Activate the theme through the **Themes** screen in WordPress.
3. Use the Site Editor to customize templates and styles.
4. After activation, an admin notice offers to install demo content (pages, posts, categories).

== Frequently Asked Questions ==

= Does this theme require any plugins? =

No, ИнфинИТи is a standalone block theme that works with WordPress 6.4+ core features.

= Can I use this theme with the classic editor? =

No, this is a full-site editing theme and requires the block editor.

= Is this theme multisite compatible? =

Yes, all functionality works correctly in a WordPress multisite environment.
