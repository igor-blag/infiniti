== Description ==

ИнфинИТи is a modern full-site editing block theme designed for children's digital education centers. It features a striking diagonal-split hero section, a deep blue and red accent color palette, and a confident forward-looking design.

**Features:**

* Full Site Editing (FSE) support
* Diagonal-split hero pattern
* Sticky header with blur backdrop
* Fullscreen mobile navigation overlay
* Search overlay with drone animation
* Custom block patterns for programs, advantages, CTA sections
* Responsive layout
* Custom color palette and typography via theme.json

== Installation ==

1. Upload the `infiniti` folder to `/wp-content/themes/`.
2. Activate the theme through the **Themes** screen in WordPress.
3. Use the Site Editor to customize templates and styles.

== Frequently Asked Questions ==

= Does this theme require any plugins? =

No, ИнфинИТи is a standalone block theme that works with WordPress 6.4+ core features.

= Can I use this theme with the classic editor? =

No, this is a full-site editing theme and requires the block editor.
